













## **Assignment Operators**

| Symbol | Description | Code Example | Code Output |
|--------|-------------|--------------|-------------|
| =      | Assigns the value or expression output on RHS to the variable name on LHS. | `x = 5`<br>`print(x)` | `5` |
| +=     | Overwrites the earlier value of x by adding the specified value.<br>e.g., `x += 10` is the same as `x = x + 10`. | `x=5`<br>`x +=10`<br>`print(x)` | `15` |
| -=     | Overwrites the earlier value of x by subtracting the specified value.<br>e.g., `x -= 10` is the same as `x = x - 10`. | `x=20`<br>`x -=6`<br>`print(x)` | `14` |
| \*=    | Overwrites the earlier value of x by multiplying the specified value.<br>e.g., `x *= 10` is the same as `x = x * 10`. | `x=7`<br>`x *=2`<br>`print(x)` | `14` |
| /=     | Overwrites the earlier value of x by dividing the specified value.<br>e.g., `x /= 10` is the same as `x = x / 10`. | `x=50`<br>`print(x /=10)`<br>`print(x)` | `5` |
