# Input and Output
* In Google Colab, the interface is divided into cells, and each cell can be used to input code or text
* **Each code cell represents an input** where you write your code. When you run the cell, the code within it is executed
* **When a code cell is executed, it generates an output** which is displayed immediately below the cell. The output could be text, a plot, a table, or any other type of result produced by the code
* Not every code cell will generate an output
